**Фокус-область от пользователя (необязательно):** $ARGUMENTS

## Шаги

1. Определи текущую ветку (`git branch --show-current`) — она должна быть `feature/NNN-*`. Если нет — сообщи пользователю, что `/clarify` работает только на ветке существующей фичи, и останови выполнение.
2. Найди `specs/NNN-feature-name/spec.md`, соответствующий текущей ветке. Если файла нет — сообщи, что сперва нужен `/specify`.
3. Вызови subagent `analyst` (Agent tool, `subagent_type: "analyst"`, foreground) с prompt: путь к `spec.md`, режим «clarify», фокус-область из `$ARGUMENTS` (если задана).
4. `analyst` не может спрашивать пользователя напрямую — если в его ответе есть блок `## ВОПРОСЫ ПОЛЬЗОВАТЕЛЮ`, файл ещё не дописан. Задай эти вопросы пользователю через `AskUserQuestion` в основном потоке, затем через `SendMessage` верни ответы тому же вызову `analyst`, чтобы он вписал их в раздел `## Clarifications` спеки. Повтори при необходимости, если агент снова вернёт вопросы.
5. После завершения — покажи пользователю обновлённый `spec.md`, явно укажи, остались ли ещё `[NEEDS CLARIFICATION]` маркеры (может понадобиться повторный `/clarify`).
6. Предложи `/commit` с аргументом «только закоммить, не мержи и не пушь».
