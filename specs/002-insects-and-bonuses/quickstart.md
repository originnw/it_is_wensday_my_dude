# Quickstart: ручная проверка (002-insects-and-bonuses)

Автоматизированные юнит-тесты (`geometry.test.ts`, `insects.test.ts`, `bonuses.test.ts`, `effects.test.ts`, `world.test.ts`, Vitest) покрывают игровую логику изнутри (AC-16 — сам факт тестируемости). Этот чеклист — дополнительная сквозная ручная проверка через реальный браузер/canvas. Роль `tester` в `/implement` проходит его целиком.

## Подготовка

```
npm install
npm run dev
```

Открыть адрес в браузере, devtools → Console (должна быть пуста от ошибок, кроме ожидаемых `score: N` — см. п.6 ниже).

## Насекомые: появление и движение

1. Понаблюдать ~30–60 секунд — насекомые периодически появляются в кадре: часть влетает сверху, часть — слева или справа. Видны минимум два различимых по виду типа (например, размером/цветом). → **AC-1**
2. Насекомое, влетевшее сбоку, движется примерно горизонтально с постоянной скоростью (без разгона/торможения на глаз) и покидает экран через противоположный боковой край, если его не съесть. Насекомое, влетевшее сверху, движется вниз и покидает экран снизу. → **AC-2**
3. Понаблюдать за высотой появления насекомых — часть из них явно ниже роста лягушки (достижимы стоя), часть — заметно выше, так что дотянуться можно только прыжком. → **AC-3**
4. Дать нескольким насекомым долететь до края экрана, не трогая их лягушкой — они просто исчезают, без какого-либо визуального «наказания» (мигания, тряски экрана и т.п.). → **AC-4**

## Поедание насекомых

5. Подвести лягушку (движение стрелками, при необходимости — прыжок/боковой прыжок из `001-frog-movement`) так, чтобы её тело пересеклось с насекомым, летящим низко. Насекомое немедленно исчезает в момент касания. → **AC-5**
6. Открыть devtools Console — при каждом поедании насекомого появляется `score: N`, число увеличивается. Съесть комара, затем стрекозу (или наоборот) — прирост числа для стрекозы заметно больше, чем для комара. → **AC-5, AC-6**
7. Дождаться насекомого на высоте, недостижимой стоя, и поймать его прыжком (вертикальным или боковым) в нужный момент полёта. → **AC-3, AC-5**

## Бонусы

8. Понаблюдать за верхним краем экрана — периодически появляются падающие объекты (бонусы), опускающиеся строго вертикально, без горизонтального смещения, с постоянной скоростью. → **AC-7**
9. Не трогая бонус, дать ему долететь до нижнего края — он исчезает без какого-либо видимого эффекта (насекомые не меняют поведение). → **AC-9**
10. Сравнить два разных бонуса визуально, не ловя их — они отличаются цветом (например, зелёный/красный), то есть тип бонуса виден заранее, до поимки. → **AC-17**
11. Поймать явно позитивный на вид бонус (телом лягушки) — сразу после этого насекомые в кадре (включая уже летевшие до поимки) становятся заметно медленнее и/или ниже. Проверить в Console — счёт (п.6) при этом не увеличился. → **AC-8, AC-10, AC-14**
12. Поймать явно негативный на вид бонус — насекомые становятся заметно быстрее и/или выше относительно обычного поведения (п.1–3). Счёт по-прежнему не увеличивается. → **AC-8, AC-11, AC-14**
13. Поймав позитивный бонус, подождать без действий, пока эффект не истечёт сам — насекомые возвращаются к обычной скорости/высоте без дополнительных действий игрока. → **AC-12**
14. Поймать позитивный бонус, затем, не дожидаясь истечения эффекта, поймать ещё один позитивный — эффект не «ослабевает» и не «усиливается» на глаз, но время до его окончания заметно продлевается (визуально дольше, чем в п.13 при одиночной поимке). → **AC-13 (тот же знак)**
15. Поймать позитивный бонус, затем, пока эффект ещё активен, поймать негативный — поведение насекомых мгновенно меняется с «легче» на «сложнее» (без промежуточного возврата к базовому уровню, наблюдаемого глазом), и это состояние держится полную длительность нового эффекта. → **AC-13 (противоположный знак)**

## Регресс управления лягушкой (AC-15)

16. Повторить пункты 1–13 и 15 (кроме проверки README, п.15 там) из `specs/001-frog-movement/quickstart.md` — движение, прыжок, боковой прыжок, приседание работают в точности как до этой фичи, появление/поедание насекомых и бонусов не мешает и не блокирует ни одно из существующих действий. → **AC-15**

## Автоматизированные тесты
