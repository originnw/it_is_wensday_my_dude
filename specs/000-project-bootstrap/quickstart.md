# Quickstart: ручная проверка (000-project-bootstrap)

Тестовый раннер в этой фиче намеренно не настраивается (см. «Не-цели» spec.md). До появления автоматизированных тестов приёмка идёт вручную по каждому AC. Роль `tester` в `/implement` проходит этот чеклист целиком.

## Подготовка

```
npm install
```

## Dev-режим

1. `npm run dev` — команда должна завершиться без ошибок в терминале и напечатать адрес (обычно `http://localhost:5173`). → **AC-1**
2. Открыть адрес в браузере, открыть devtools → Console. Консоль пуста от ошибок. На странице есть `<canvas>`, растянутый на весь viewport (ширина/высота canvas совпадают с окном браузера на момент загрузки). → **AC-2**
3. Сразу после загрузки canvas закрашен видимым цветом, не прозрачный/пустой. → **AC-3**
4. В углу экрана виден FPS-счётчик, число обновляется во времени (не застыло на одном значении, меняется по мере работы цикла). → **AC-4**
5. (Опционально, для доверия к AC-5) В devtools или через временный `console.log` проверить, что `deltaTime` — не константа, а меняется между кадрами, и нигде в коде нет захардкоженных «16.6 мс»/«1/60». → **AC-5**
6. На странице и в исходниках `src/` нет никаких игровых сущностей — ни лягушки, ни препятствий, ни счёта, ни game over/restart экрана, ни обработки клавиатуры/тача. Единственное содержимое — закрашенный canvas и dev-only FPS-счётчик. → **AC-9**

## Продакшн-сборка

7. `npm run build` — завершается без ошибок и без предупреждений уровня error/type-error, создаёт директорию `dist/` со статическими файлами. → **AC-6**
8. `npm run preview` (или любой статический HTTP-сервер поверх `dist/`). Открыть адрес в браузере:
   - Консоль без ошибок, canvas виден, растянут на весь viewport, закрашен, цикл непрерывно тикает (повторяет AC-2/AC-3/AC-5 в проде). → **AC-7**
   - FPS-счётчик в этой сборке не обязателен — присутствует он или нет, приёмке не мешает.

## TypeScript strict mode

9. `npx tsc --noEmit` (или проверить, что `npm run build` включает проверку типов) — завершается без ошибок типов, `tsconfig.json` содержит `"strict": true`. → **AC-8**

## README

10. Открыть `README.md` в корне репозитория — присутствуют секции с командами установки, dev-запуска (`npm run dev`) и сборки (`npm run build`). → **AC-10**

## Итог

Чеклист пройден полностью → все AC-1..AC-10 закрыты, фича готова к финальному коммиту `/implement`.
