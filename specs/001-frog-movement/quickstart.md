# Quickstart: ручная проверка (001-frog-movement)

Автоматизированные юнит-тесты (`src/game/frog.test.ts`, Vitest) покрывают логику `updateFrog()` изнутри (AC-12 — сам факт тестируемости). Этот чеклист — дополнительная сквозная ручная проверка через реальный браузер/клавиатуру/canvas, которую юнит-тесты не эмулируют. Роль `tester` в `/implement` проходит его целиком.

## Подготовка

```
npm install
npm run dev
```

Открыть адрес в браузере, devtools → Console (должна быть пуста от ошибок).

## Горизонтальное движение

1. Зажать стрелку влево — лягушка движется влево с постоянной скоростью, без разгона. Отпустить — останавливается мгновенно, без доката. → **AC-1, AC-2**
2. То же для стрелки вправо. → **AC-1, AC-2**
3. Держать стрелку влево, пока лягушка не упрётся в левый край canvas — движение прекращается у края, лягушка не телепортируется на правый край, экран не скроллится. Зажать стрелку вправо — движение возобновляется немедленно. Повторить для правого края. → **AC-3**
4. Зажать одновременно стрелки влево и вправо — лягушка неподвижна по горизонтали, никакого дёрганья. Отпустить одну из клавиш — движение в сторону оставшейся зажатой клавиши начинается сразу. → **AC-4**

## Прыжки

5. Нажать пробел, не трогая стрелки — лягушка плавно поднимается и опускается по дуге, возвращается точно на исходную высоту (не телепорт вверх/вниз). → **AC-5**
6. (Опционально, доверие к AC-6) Замедлить вкладку (throttling CPU в devtools) или сравнить визуально на разных мониторах/FPS — длительность прыжка по ощущению одинакова по времени, не «медленнее/быстрее» в зависимости от FPS. → **AC-6**
7. Во время прыжка (пока лягушка в воздухе) повторно нажать пробел несколько раз — новый прыжок не запускается, лягушка приземляется на исходном уровне, и только после этого следующее нажатие пробела снова поднимает её. → **AC-7**
8. Зажать стрелку вправо (или влево) и нажать пробел — лягушка одновременно прыгает по той же дуге и смещается в сторону зажатой стрелки. → **AC-8**
9. Во время прыжка (вертикального или бокового) нажимать/отпускать стрелки влево/вправо — горизонтальная позиция реагирует так же отзывчиво, как на земле (AC-1–AC-3), включая упор в край экрана, без зависаний/рывков. → **AC-9**

## Приседание

10. Зажать Left Ctrl, стоя на месте — лягушка визуально отличимо меняет позу (иная форма/размер на canvas). Отпустить — поза мгновенно возвращается к обычной. → **AC-10**
11. Зажать Left Ctrl одновременно со стрелкой влево/вправо — лягушка приседает и одновременно продолжает двигаться по горизонтали. → **AC-11**
12. Прыгнуть (пробел), в полёте зажать и удерживать Left Ctrl — поза приседания не появляется, пока лягушка в воздухе; после приземления, если Left Ctrl всё ещё зажат, поза приседания появляется. → **AC-11**

## Автоматизированные тесты

13. `npm run test` — все тесты `frog.test.ts` проходят, подтверждая, что логика `updateFrog()` вызывается и проверяется без DOM/canvas окружения (без `jsdom` в конфигурации Vitest). → **AC-12**

## README

14. Открыть `README.md` — присутствует раздел «Управление» с описанием стрелок влево/вправо, пробела (включая боковой прыжок в сочетании со стрелкой) и Left Ctrl. → **AC-13**
