# it's wednesday my dude

Пиксельная браузерная игра про лягушку из мема «it's wednesday my dude» — геймплейный референс: офлайн-динозавр Chrome.

## Зачем этот репозиторий на самом деле

Игра здесь вторична. Первичная цель — учебный полигон для отработки **agentic-разработки и spec-driven development (SDD) с Claude Code**: полный цикл `constitution → specify → clarify → plan → tasks → analyze → implement`, реализованный через мультиагентный workflow (аналитик, архитектор, разработчик, тестировщик, ревьюер — отдельные субагенты). Итоговый процесс задуман как переносимый фреймворк для рабочих задач.

Полное описание процесса — [`docs/sdd-workflow.md`](docs/sdd-workflow.md).

## Стек

TypeScript + Vite + HTML5 Canvas. Статический бандл: сейчас деплой на GitHub Pages, позже — VPS/Netlify без смены архитектуры.

## Статус

Каркас проекта готов: Vite + TypeScript + HTML5 Canvas с игровым циклом на `requestAnimationFrame` (фича `specs/000-project-bootstrap`). Управление лягушкой (перемещение, прыжок, приседание) реализовано — см. раздел «Управление» ниже (фича `specs/001-frog-movement`). Препятствий и счёта пока нет — они появятся в следующих фичах.

## Установка

```bash
npm install
```

Устанавливает зависимости проекта (Vite, TypeScript) из `package.json`.

## Разработка

```bash
npm run dev
```

Поднимает локальный dev-сервер (Vite) с автообновлением страницы при изменении исходников (HMR). Адрес сервера печатается в терминале после запуска.

## Сборка

```bash
npm run build
```

Проверяет типы (`tsc`) и собирает продакшн-бандл — статические файлы в `dist/`, не требующие бэкенда.

```bash
npm run preview
```

Поднимает локальный сервер, отдающий содержимое `dist/`, — позволяет проверить собранный бандл так, как он будет работать в проде.

## Управление

- **Стрелка влево / вправо** — перемещение лягушки по горизонтали.
- **Пробел** — прыжок вверх. Если во время нажатия зажата стрелка влево или вправо — получается боковой прыжок (прыжок совмещается с движением в сторону). Прыжок доступен и во время приседания — в этом случае лягушка прыгает выше обычного.
- **Left Ctrl** — присесть (удерживать для сохранения присевшей позы).
